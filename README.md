
# Post review manager for buffer.com

## Idea

Provide stakeholders with a simple way of reviewing and approving a social media post from buffer. Send a post link-no account creation, passwords. 

User that opens the link is logged in just on that post.
He can review or approvea the post.
Browser automatically stores a cookie for that user and burns the link. Giving the illusion of being logged in.

Login is done by saving a cookie.

## Getting started

`npm run dev` for development mode for web.
